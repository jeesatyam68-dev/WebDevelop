Here we will learn the rules of naming variables

RULES OF WRITTING VARIABLE

  • ALWAYS START A VARIABLE NAME WITH EIGHTHER
    • NAME
    • OR "_"
    • OR "$"
  • Use camel case
    • EXAMPLE:- let userName
  • Be descriptive and meaningful
  • Avoid using reserved keywords
    • example:- let var; (it'll show error)
  • No spaces or special characters
    • example:- let user-name; // Invalid

SUMMARY

Use camelCase.
Start names with a letter, _, or $.
Avoid JavaScript keywords.
Avoid spaces and special characters.
Choose meaningful names.
