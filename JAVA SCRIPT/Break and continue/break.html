Here we wills see how break and continue works in java script

Break

    Break:-The break statement is used to exit a loop prematurely, before the loop condition evaluates to false.

    example:- 
    let i= 10;

    for(i=2; i<10;i++){
        if(i==5){
        break;

        }
        console.log(i)
    }

     while:-
    let i=10;

    while(i<20){
        console.log(i);
        i++
    }

    do while:-

    let b=10;

    do{
        if(b==25){
        break;

        }
        console.log(b);
        b++
    }while(b<30)
