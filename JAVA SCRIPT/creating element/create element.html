        1. Creating Elements
        Use document.createElement() to create a new HTML element in memory (not yet in the DOM).
    
        2. Appending Elements
        Use methods like appendChild() or append() to insert an element into the DOM.

        3. Prepending Elements
        Use prepend() to insert an element at the beginning of the parent.

        4. Removing Elements
        To remove an element, you can use:
        a) removeChild() (from parent)
        b) remove() (directly on the element)


        Summary
        Task	Method
        Create element	              document.createElement()
        Set text content	              element.textContent
        Add attribute or class	              setAttribute(), classList.add()
        Append to parent	              appendChild(), append()
        Prepend to parent	              prepend()
        Remove from parent	              parent.removeChild(child)
        Remove element directly	              element.remove()
